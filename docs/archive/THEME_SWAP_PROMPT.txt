**Goal:**

**Instructions:**

    - **TabBarTheme**: Set `labelColor` and indicator color to `AppColors.secondary`.
    - **SwitchTheme**, **CheckboxTheme**, **RadioTheme**: Update active colors to `AppColors.secondary`.

**Output:**
Apply these changes directly to `lib/core/theme/app_theme.dart`. Do NOT change `app_colors.dart`.
