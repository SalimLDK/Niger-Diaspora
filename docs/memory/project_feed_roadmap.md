Le feed (`lib/features/feed/`) est **déjà mature** : modes forYou (algorithmique, `feed_scorer.dart`) / following / recent, infinite scroll, pull-to-refresh, hashtags pondérés, boost pays, posts texte+photos, @mentions, like simple, commentaires à plat, partage, bookmarks, slots pub. ~30 features adjacentes couvrent déjà DM, appels, audio_rooms (+ monétisation), podcasts, events, groups, marketplace, map, modération, offline/compression.

**Objectif retenu (2026-06-26) = engagement / rétention**, mais roadmap couvre 4 objectifs (engagement, diaspora, faible bande passante, monétisation).

P0 à ajouter : (1) notifs d'engagement sur posts — ✅ VÉRIFIÉ : la logique existe (`functions/index.js` : `onPostLiked`, `onPostCommented`, `onCommentMention`, `onNewPostCreated`) mais ce sont des triggers **Firestore** orphelins → jamais déclenchés car le feed écrit dans Supabase (cf. [[project_supabase_schema_drift]]). Donc 0 notif d'engagement aujourd'hui. Tâche = re-câbler vers Supabase (webhook/trigger pg sur `post_likes`/`post_comments`, ou émettre depuis `feed_supabase_datasource.dart`). (2) réactions multiples (réutiliser l'infra réactions des messages) ; (3) réponses imbriquées + likes commentaires (`parent_comment_id` déjà en base) ; (4) reprise de lecture.
P1 : sondages, suggestions de comptes + feedback « moins/plus de ça », brouillons+édition, sélecteur Niger/Diaspora/Tout, cache offline persistant, posts sponsorisés + « booster un post » (réutiliser boost `businesses`).

**Repost/repartage** (demandé explicitement) : `share_count` existe sur `posts` mais jamais incrémenté (à réutiliser) ; nouvelle table `post_reposts` (pattern `post_likes`/`post_bookmarks`, + `comment` nullable pour la citation) ; 2 variantes (repost simple / avec commentaire) via l'icône 🔁 de `post_card.dart` ; bandeau « 🔁 X a reposté » dans le feed. Routes (conventions existantes `/feed/...` contenu, `/profile/...` listes) : `/profile/reposts` (mes repartages, jumeau de MyPostsScreen), onglet « Partages » dans la vue profil, `/feed/:postId/reposts` (qui a reposté). Routing : `lib/core/router/app_router.dart`.

Écartés : IA/LLM (aucun LLM dans l'app), live vidéo, stories, gamification, posts vidéo/GIF/PDF (coût data Sahel).

**Implémenté le 2026-06-26** (flutter analyze OK) : (a) repost/repartage complet — migration `20260626100000_post_reposts.sql`, datasource/repo/provider (`toggleRepost`/`repostWithComment`/`getRepostedPosts`/`getReposterIds`, `FeedState.repostedPostIds`), bouton 🔁+sheet dans post_card, écrans `/profile/reposts` + `/feed/:postId/reposts` ; (b) notifs d'engagement re-câblées via `NotificationService().createNotification` (enum + switches : postLiked/postCommented/commentReply/postReposted, deep-link `/feed/:postId`).
